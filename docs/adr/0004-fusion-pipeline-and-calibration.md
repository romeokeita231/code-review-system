# 0004 融合四阶段与校准口径

- Status: Accepted
- Date: 2026-11-11
- Source: #10、#16、#12

## Context

两源不可见、量纲不同，且标注集规模有限。直接取最大置信度等于无条件相信最自信者；简单平均忽略类别间可靠度差异。校准与阈值容易把 fit 集的信息泄漏进标签生成路径。

## Decision

- 融合固定四步：归并判定（去重）→ 冲突消解 → 置信度校准 → 加权投票；每步独立可开关，B3 即四步全关。
- 归并 key = 文件 + 行区间相交 + 类别可比（双方都有 CWE 必须相同；一方缺 CWE 则只比位置）。相邻但不同类不许合并。
- 冲突消解：evidence 可核验者优先；均成立交投票；均不可判定降级为纠偏或待复核，不得升为阻断；两源无多数决。
- 校准按 `source × category` 格（28 格）：连续收缩 `n0 = 10` 到先验 → 格内 PAVA 档位单调化 → 截断 `[p_prior, 0.95]`。单调化不单列 stage，「关校准」同时关掉收缩与单调化。
- 权重只区分单源 / 双源：`w = 1` / `w = 0.75`（相关性折扣）；融合分 `L = logit(p_prior) + w · Σe`。不取 max、不取平均；Dawid-Skene / EM 不在 v1。
- 阈值全局 0.90（阻断）/ 0.70（纠偏）；按 L 降序累计精确率取最低合格切点；切点之上需 ≥10 条 fit 声明；类内声明 <30 条时不启用类内阈值。
- 标签生成路径不得出现任何由 fit 集估计出的量；允许 GT、几何关系、源原始字段。
- 校准在 fit 247 上一次性冻结，`configHash` 覆盖权重与阈值。

## Consequences

- 校准产物是可版本化的数据文件，不是运行时拟合。
- 类内阈值在样本不足时静默退化为全局阈值，报告必须说明。
- 双源折扣使 B3→B4g 的差值同时包含「去重/消解」与「折扣」，解释时须拆开叙述。
